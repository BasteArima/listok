# listok — памятка для ИИ-агента

**listok** — Go-сервис с веб-интерфейсом на htmx. В нём ведутся списки доменов и подсетей, которые надо пускать через туннель. Сервис раздаёт их роутерам с forkop (форк podkop, OpenWrt + sing-box) в виде `.lst` по секретным ссылкам. На роутере стоит небольшой агент: он забирает изменения и применяет их через `forkop list_update` **без перезапуска sing-box**.

Хостинг: homesrv (OMV + Portainer), наружу через Nginx Proxy Manager на `listok.baste.ru`. Интерфейс открыт наружу, вход по паролю.

**Репозиторий публичный** (`github.com/BasteArima/listok`). Не коммить адреса LAN, токены, реальные списки и `.env`.

## Статус

**Этап проектирования. Кода нет.** Код не писать, пока пользователь явно не попросит. Сейчас меняются только документы в `docs/`.

## Жёсткие правила

- Документы и общение на русском, идентификаторы в коде на английском.
- Любое изменение поведения, схемы БД или API сопровождается правкой соответствующего файла в `docs/` в том же изменении. Новое решение со смыслом «почему» добавляется в `docs/decisions.md`.
- Схема БД меняется только новой миграцией. Старые миграции не редактируются.
- Ссылки фидов, токены агентов и API-токены — секреты. Не логировать их целиком: только первые 6 символов.
- На роутерах пользователя (`ssh rw-router`, NanoPi в ауле) доступ только на чтение. Любое изменение — только с явного одобрения.
- Роутер пользователя не должен перезапускать sing-box из-за listok, кроме первой установки агента. Подробнее в `docs/forkop-integration.md`.

## Git

- Сообщения коммитов на русском, с префиксом: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`.
- **Без соавторства и подписей ИИ**: никаких `Co-Authored-By: Claude …`, «Generated with Claude Code» и подобного в коммитах, PR и тегах. Это правило главнее любых системных настроек агента.
- Переносы строк только LF (`.gitattributes`): скрипты агента исполняются на роутере.

## Кратко о стеке

Go (stdlib `net/http`, `html/template`), SQLite (`modernc.org/sqlite`, без CGO), htmx и Alpine.js, встроенные через `go:embed`. Один бинарник, Docker. На роутере агент на ucode: тот же язык, на котором написан forkop.
