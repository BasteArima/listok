Новый фид

Фид — это один .lst для одной секции forkop (обычно main; для отдельного выхода — например, geo). В него войдут включённые записи отмеченных списков.

Видимых списков нет — фид будет пустым (только служебная запись).

{{end}}

Как подключить к forkop

  1. LuCI → forkop → нужная секция → Domain and IP lists → вставить ссылку фида → сохранить.
  2. forkop перезапустится один раз и скачает список. Дальше он обновляет его сам раз в сутки (update_interval), без перезапуска sing-box.
  3. Первая строка фида — служебная listok-sentinel.invalid: она нужна, чтобы новые записи подхватывались без рестарта.

Пока нет агента: после перезагрузки роутера список по URL может не подхватиться до повторного перезапуска forkop (гонка при старте). Агент listok уберёт и это, и суточную задержку.
