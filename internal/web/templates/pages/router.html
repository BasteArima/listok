Новый фид

Фид — это один .lst для одной секции forkop (обычно main; для отдельного выхода — например, geo). В него войдут включённые записи отмеченных списков.

Как подключить к forkop

С агентом (рекомендуется): блок «Агент на роутере» выше → «Выдать ссылку установки» → выполнить команду на роутере. Агент держит файлы фидов локально и применяет изменения за секунды через forkop list_update, без перезапуска sing-box.

Без агента: LuCI → forkop → секция → Conditions → Domain and IP lists → вставить ссылку фида и нажать + → Save & Apply (если LuCI откатил изменение — «Apply unchecked»). forkop обновит список раз в сутки.

Без агента после перезагрузки роутера список по ссылке может не подхватиться до повторного перезапуска forkop (гонка при старте).
