Расширение для Chrome

Работает в Chrome на Windows и Mac, а также в Edge. Версия {{.ExtensionVersion}}. Chrome предупредит, что расширение читает данные на всех сайтах: так оно видит, какие домены страницы не загрузились. Домены уходят только на этот сервис.

  1. Скачайте расширение и распакуйте в папку, которая никуда не денется. Новая версия: замените файлы в папке и нажмите «Обновить» на странице расширений.
  2. Откройте chrome://extensions, включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку.
  3. Создайте токен выше и вставьте строку подключения в настройки расширения.

Значок удобно закрепить на панели. С клавиатуры: Alt+Shift+L, затем Enter.

Команда для iPad и iPhone

Добавляет сайт из меню «Поделиться» в Safari. Аккаунт разработчика не нужен.

{{if .ShortcutReady}}
  1. Откройте эту страницу на iPad, создайте токен и скопируйте строку подключения.
  2. Скачайте команду, откройте файл, нажмите «Добавить команду» и вставьте строку.
  3. В Safari: «Поделиться» → «В listok» → выберите список.
{{end}}
Собрать вручную
  1. «Команды» → новая команда → в настройках команды включите «Показывать в Поделиться» и оставьте типы «URL» и «Веб-страницы Safari».
  2. Добавьте действие «Получить содержимое URL». Адрес — из таблицы ниже, метод POST, заголовок Authorization со значением Bearer ваш-токен, тело JSON с полем input типа «Текст» и значением «Ввод команды».
  3. Добавьте «Получить значение из словаря» с ключом message и «Показать уведомление» с результатом.
