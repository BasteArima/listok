# Фиды (`internal/feed`)

## Содержимое

Фид = объединение **включённых** записей всех списков из `feed_lists` с рекурсивным раскрытием `list_includes`.

1. Собрать множество значений и убрать дубли.
2. Убрать записи, покрытые другими записями фида (`a.youtube.com` при наличии `youtube.com`; `/24` внутри `/16`).
3. Отсортировать: сначала домены, потом IPv4, потом IPv6, внутри по алфавиту или по адресу.
4. **Сторожевая запись**: первой строкой всегда идёт `listok-sentinel.invalid`. Зона `.invalid` зарезервирована (RFC 2606), реального трафика туда нет. Благодаря ей rule-set на роутере никогда не пуст и всегда содержит доменный матчер. Тогда forkop при генерации конфига регистрирует его и в route-, и в DNS-правилах, а домены, добавленные позже, получают FakeIP без рестарта (`forkop-integration.md`, П-6).
5. Формат: одна запись на строку, `\n`, в конце перевод строки. **Без комментариев** (`forkop-integration.md`, П-3).

`ETag` = `"` + первые 16 hex-символов от sha256(содержимого) + `"`. Содержимое и ETag кешируются в памяти и пересчитываются при изменении любого входящего в фид списка.

## Long-poll

`GET /f/{token}.lst?wait=55` с `If-None-Match: <etag>`:
- если ETag отличается → сразу `200` и содержимое;
- если совпадает → запрос ждёт события от `Notifier` по этому фиду до `wait` секунд. Пришло изменение → `200`, вышел таймаут → `304`.

`wait` ограничен сверху значением `LISTOK_LONGPOLL_MAX` (по умолчанию 55). Таймаут чтения NPM по умолчанию 60 с; больше 55 ставить, только если в NPM поднят `proxy_read_timeout` (`deploy.md`).

`Notifier`: map `feedID → канал, закрываемый при изменении` (broadcast через закрытие и замену канала). Без внешних брокеров.

## Учёт

Каждая отдача пишется в `feed_fetches`, и обновляются `feeds.last_fetch_at` и `last_etag`. На экране роутера видно: «забрал версию `ab12…` 40 с назад». Если `last_etag` ≠ текущему ETag, роутер отстаёт.

## Безопасность

- Токен: 32 случайных байта в base62. Перевыпуск делает старую ссылку недействительной сразу.
- Ограничение частоты по токену и IP. Неверный токен → 404.
