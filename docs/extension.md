# Расширение браузера и команда для iPad

Быстрое добавление текущего сайта без входа в listok. Оба клиента ходят в `/api/v1` с токеном (`api.md`, D-040).

| Где | Что | Аккаунт разработчика |
|---|---|---|
| Chrome на Windows и Mac | расширение `extension/` | не нужен |
| Safari на iPad и iPhone | команда в меню «Поделиться» (`shortcut/`) | не нужен |
| Safari на Mac | не поддерживается, см. D-041 | |

## Токены

Вкладка «Подключения» (`/connections`): создать токен с названием, увидеть первые символы и последний запрос, отозвать. Токен виден один раз, в БД только хеш. Сразу после создания страница показывает:
- **строку подключения** `адрес#токен` (адрес — `LISTOK_BASE_URL`) для расширения и команды на iPad;
- **токен** для ручной сборки команды.

Токен даёт видеть списки владельца и добавлять записи, с теми же правами. Сессия из cookie на `/api/v1` не действует.

## Расширение (`extension/`)

Manifest V3, без сборки и зависимостей. Файлы встроены в бинарник (`extension/extension.go`), вкладка «Подключения» отдаёт их архивом `/extension.zip`.

Установка: распаковать архив, `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное». Обновляется вручную: заменить файлы в папке и нажать «Обновить» на той же странице. Версия — в `manifest.json`, её показывает вкладка «Подключения».

### Окошко (`popup.js`)

- Поле с галочкой заполнено хостом активной вкладки, в том числе если сайт не открылся: браузер отдаёт адрес, который пытались открыть. На служебных страницах поле пустое и в фокусе. Если сайт уже есть в списке, галочка снята.
- **«Не загрузилось на этой странице»**: домены с галочками. Отмечены те, что не загрузились совсем и ещё не добавлены. Подпись: «2 запроса», «часть загрузилась» (без галочки), «уже в „Общий“» (без галочки).
- **«Остальные домены страницы»**, свёрнуто, без галочек и без уже добавленных. Для замедления: заторможенный домен формально не падает.
- Список: последний использованный, при первом запуске первый из доступных для добавления. Комментарий и «только этот хост» свёрнуты.
- Кнопка в фокусе и говорит, что будет сделано: «Добавить», «Добавить 3 домена». Значок, затем Enter. Сочетание для значка — `Alt+Shift+L` (меняется в `chrome://extensions/shortcuts`).
- Хосты сводятся к доменам сервисом (`GET /api/v1/check`), как при добавлении. Всё отмеченное уходит одной версией.
- Успешное добавление закрывает окошко через 1,5 с. «Уже есть» и ошибки остаются на экране.
- Список списков берётся из прошлого запуска и обновляется в фоне: окошко не ждёт сеть.

### Что считается незагруженным (`background.js`)

Фоновый скрипт наблюдает запросы вкладки (`webRequest`, без блокировки) и ведёт по хостам счётчики `failed` и `ok`. Новая загрузка страницы начинает заново. Состояние в `storage.session`: браузер останавливает простаивающий скрипт.

- **Считается:** сетевые ошибки (`ERR_CONNECTION_*`, `ERR_TIMED_OUT`, `ERR_NAME_NOT_RESOLVED`, `ERR_SSL_*`, `ERR_CERT_*`, `ERR_QUIC_*`, `ERR_HTTP2_*`, `ERR_EMPTY_RESPONSE` и прокси) и запросы без заголовков ответа дольше 15 с.
- **Не считается:** `ERR_ABORTED` (страница отменила сама), если запрос не висел дольше 15 с; `ERR_BLOCKED_BY_*` (блокировщик рекламы); нет интернета вообще; `ping`, `csp_report`; локальные адреса и IP.

Счётчик на значке — домены, которые не загрузились и ещё ни в одном списке. SwitchyOmega считает проблемой 5 с без заголовков, поэтому показывает ресурсы, которые потом загружаются. Запросы сервис-воркера страницы к вкладке не относятся и не видны.

### Настройки (`options.js`)

Строка подключения заполняет адрес и токен. Необязательный запасной адрес. «Сохранить и проверить» проверяет каждый адрес отдельно. Всё хранится в `chrome.storage.local`, в синхронизацию токен не попадает.

### Два адреса (`client.js`)

Сначала пробуется адрес, сработавший в прошлый раз, потом остальные. На следующий адрес переходим, если нет связи за 4 с, ответ 5xx или ответ не похож на listok. Ответ самого listok (401, 403, 404, 422) окончательный. Повторить добавление безопасно: запись получит статус «уже есть».

**Адрес в локальной сети.** `deploy/compose.yml` публикует порт только для NPM на `172.17.0.1`, из домашней сети напрямую сервис недоступен. По IP через NPM тоже не выйдет: сертификат выдан на домен. Варианты:
1. Подменить домен в DNS роутера на адрес сервера (`deploy.md`, п. 6). Адрес остаётся один, с HTTPS. Запасной не нужен.
2. Опубликовать порт на адресе в сети и указать `http://<IP>:<порт>` как запасной. Токен пойдёт по сети открытым текстом, настройки об этом предупреждают. Chrome может дополнительно спросить разрешение на доступ к локальной сети.

### Разрешения

`storage`, `webRequest` и доступ ко всем сайтам (`<all_urls>`): без него не видно запросы страницы, D-042. Chrome предупредит об этом при установке. Запросы только наблюдаются. Домены хранятся локально и уходят только на настроенный сервис: при проверке покрытия и добавлении.

## Команда для iPad и iPhone (`shortcut/`)

**Для пользователя:** на вкладке «Подключения» на iPad создать токен, скопировать строку подключения, скачать команду, открыть файл, нажать «Добавить команду» и вставить строку. Дальше в Safari: «Поделиться» → «В listok» → выбрать список → уведомление с итогом. Незагруженные домены команда не видит, только адрес страницы.

**Как устроена:** при запуске берёт `menu` из `GET /api/v1/lists`, показывает названия, отправляет адрес страницы в выбранный список, показывает `message`. Ссылку разбирает сервер. Запасного адреса нет: при ошибке связи команда останавливается.

**Сборка.** `shortcut/shortcut.go` описывает команду, `go run ./shortcut/generate` пишет `listok.plist`. iOS не импортирует файл без подписи, а подпись есть только на Mac:

```bash
sh shortcut/sign.sh
```

Получившийся `shortcut/listok-signed.shortcut` коммитится: адреса и токена в нём нет, сервис встраивает его в бинарник и отдаёт по `/shortcut/listok.shortcut`. Пока файла нет, вкладка показывает только ручную сборку. Изменили команду — сгенерировать и подписать заново (`TestPlistUpToDate` напомнит про первое). Формат файла Apple не документирует: ключи взяты из открытых генераторов (Cherri, shortcuts-js).

**Вручную**, если файл не подошёл: шаги на вкладке «Подключения», свёрнутый блок «Собрать вручную».

## Что проверено

Chromium 149 с локальным сервером и подменёнными именами хостов (2026-11-03). Настоящие запросы страницы: закрытый порт и молчащий сервер считаются, отменённый страницей запрос и живой хост — нет; зависший появляется через 15 с; хосты одного домена сводятся; уже добавленное без галочки; счётчик на значке; добавление нескольких доменов одной версией; новая загрузка страницы. Также: строка подключения, значения по умолчанию, запоминание списка, запасной адрес, ошибки связи, неверный токен. Значок в автотесте не нажать: окошко открывалось вкладкой, активная вкладка подменялась.

**Ещё не проверено:** настоящий клик по значку, настоящие сайты с блокировками, Chrome на Mac, запасной адрес на настоящем IP в локальной сети. Команда: `listok.plist` на Windows не импортировать, подпись и импорт на iPad ещё не пробовались, как и «Поделиться» на странице неоткрывшегося сайта в Safari.
