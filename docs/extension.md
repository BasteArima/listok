# Расширение браузера и команда для iPad

Быстрое добавление текущего сайта без входа в listok. Оба клиента ходят в `/api/v1` с токеном (`api.md`, D-040).

| Где | Что | Аккаунт разработчика |
|---|---|---|
| Chrome на Windows и Mac | расширение `extension/` | не нужен |
| Safari на iPad и iPhone | команда в меню «Поделиться» | не нужен |
| Safari на Mac | не поддерживается, см. D-041 | |

## Токены

Вкладка «Подключения» (`/connections`): создать токен с названием, увидеть первые символы и последний запрос, отозвать. Токен виден один раз, в БД только хеш. Сразу после создания страница показывает:
- **строку подключения** `адрес#токен` (адрес — `LISTOK_BASE_URL`) для настроек расширения;
- **токен** для команды на iPad.

Токен даёт видеть списки владельца и добавлять записи, с теми же правами. Сессия из cookie на `/api/v1` не действует.

## Расширение (`extension/`)

Manifest V3, без сборки и зависимостей. Файлы встроены в бинарник (`extension/extension.go`), вкладка «Подключения» отдаёт их архивом `/extension.zip`.

Установка: распаковать архив, `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное». Обновляется вручную: заменить файлы в папке и нажать «Обновить» на той же странице. Версия — в `manifest.json`, её показывает вкладка «Подключения».

### Окошко (`popup.js`)

- Поле «Сайт» заполнено хостом активной вкладки, в том числе если сайт не открылся: браузер отдаёт адрес, который пытались открыть. На служебных страницах поле пустое и в фокусе.
- «Только этот хост» снята, комментарий пуст. Выбран последний использованный список, при первом запуске — первый из доступных для добавления.
- Кнопка «Добавить» в фокусе: значок, затем Enter. Сочетание для значка — `Alt+Shift+L` (меняется в `chrome://extensions/shortcuts`).
- Под полем — что реально добавится и где это уже есть (`GET /api/v1/check`).
- Успешное добавление закрывает окошко через 1,5 с. «Уже есть» и ошибки остаются на экране.
- Список списков берётся из прошлого запуска и обновляется в фоне: окошко не ждёт сеть.

### Настройки (`options.js`)

Строка подключения заполняет адрес и токен. Необязательный запасной адрес. «Сохранить и проверить» просит у браузера доступ к указанным адресам и проверяет каждый отдельно. Всё хранится в `chrome.storage.local`, в синхронизацию токен не попадает.

### Два адреса (`client.js`)

Сначала пробуется адрес, сработавший в прошлый раз, потом остальные. На следующий адрес переходим, если нет связи за 4 с, ответ 5xx или ответ не похож на listok. Ответ самого listok (401, 403, 404, 422) окончательный. Повторить добавление безопасно: запись получит статус «уже есть».

**Адрес в локальной сети.** `deploy/compose.yml` публикует порт только для NPM на `172.17.0.1`, из домашней сети напрямую сервис недоступен. По IP через NPM тоже не выйдет: сертификат выдан на домен. Варианты:
1. Подменить домен в DNS роутера на адрес сервера (`deploy.md`, п. 6). Адрес остаётся один, с HTTPS. Запасной не нужен.
2. Опубликовать порт на адресе в сети и указать `http://<IP>:<порт>` как запасной. Токен пойдёт по сети открытым текстом, настройки об этом предупреждают. Chrome может дополнительно спросить разрешение на доступ к локальной сети.

### Разрешения

`activeTab` (адрес вкладки только по нажатию на значок), `storage`, адрес сервиса — `optional_host_permissions`, спрашивается в настройках. Отказ не ломает работу по https: `/api/v1` отвечает с CORS.

## Команда для iPad и iPhone

Собирается один раз в приложении «Команды»:

1. Новая команда → в её настройках включить «Показывать в Поделиться», типы ввода — URL и веб-страницы Safari.
2. Действие «Получить содержимое URL»:
   - адрес `https://listok.example.com/api/v1/lists/<адрес-списка>/entries` (готовые адреса — на вкладке «Подключения»);
   - метод `POST`;
   - заголовок `Authorization`: `Bearer <токен>`;
   - тело JSON, поле `input` типа «Текст» со значением «Ввод команды». Ссылку разбирает сервер.
3. «Получить значение из словаря», ключ `message`, затем «Показать уведомление» с результатом.

Несколько списков: «Выбрать из меню» перед запросом или отдельная команда на список. Запасного адреса в команде нет: при ошибке связи она останавливается.

## Что проверено

Chromium 149 с локальным сервером (2026-11-02): строка подключения, проверка адресов, адрес вкладки на неоткрывшемся сайте (`tabs.query` отдаёт настоящий URL), значения по умолчанию, Enter, запоминание списка, «уже есть» и «уже покрыто», служебные страницы, переход на запасной адрес и запоминание рабочего, обе ошибки связи, неверный токен, работа без доступа к адресу (через CORS). Значок в автотесте не нажать: окошко открывалось вкладкой, активная вкладка подменялась.

**Ещё не проверено:** настоящий клик по значку (`activeTab`), Chrome на Mac, запасной адрес на настоящем IP в локальной сети, сама команда на iPad, в том числе «Поделиться» на странице неоткрывшегося сайта в Safari.
