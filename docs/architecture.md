# Архитектура

## Компоненты

```
 браузер/телефон (htmx, PWA)          роутер N (OpenWrt + forkop)
        │  сессия                            │  listok-agent (ucode, procd)
        ▼                                    │   ├─ GET /f/<token>.lst  (long-poll, ETag)
 ┌──────────────────────────┐                │   ├─ POST /agent/v1/report (clash API)
 │ listok (Go, один бинарник)│◄───────────────┘   └─ пишет /etc/listok/<section>.lst
 │  web (htmx) │ /api/v1    │                         → forkop list_update
 │  feeds      │ /agent/v1  │                         (sing-box без перезапуска)
 │  remote-fetcher, jobs    │
 │  SQLite (WAL) /data      │
 └──────────────────────────┘
        ▲ NPM (listok.<домен>), homesrv
```

## Поток данных

1. Пользователь добавляет запись. Ввод нормализуется (`normalization.md`), у списка поднимается `version`, в `list_versions`/`entry_changes` пишется история.
2. Оповещатель `feeds.Notifier` пересчитывает содержимое затронутых фидов (с учётом вложенных списков) и их ETag. Ожидающие long-poll запросы получают ответ.
3. Агент на роутере получает новый `.lst`, атомарно записывает файл в `/etc/listok/` и вызывает `forkop list_update`. forkop пересобирает local rule-set в `/tmp` (sing-box перечитывает его сам) и добавляет подсети в nft-сет.
4. Раз в N минут агент шлёт на сервер выжимку из clash API: хосты, которые ушли мимо туннеля. Из них получаются подсказки в интерфейсе (`router-agent.md`).

## Фоновые задачи (внутри процесса)

- `remote-fetcher`: обновляет списки типа `remote` (внешние `.lst`, например itdoginfo) по своему интервалу.
- `expirer`: выключает временные записи (`entries.expires_at`).
- `retention`: чистит `feed_fetches` и старые наблюдения.
- `backup`: ночной `VACUUM INTO /data/backups/...`.

## Свойства, на которые опирается дизайн

- Если сервис лежит, роутеры живут с последним файлом в `/etc`. Сервис не точка отказа для трафика.
- Входящих соединений к роутерам нет: роутеры только тянут данные сами. Работает за CGNAT.
- Один процесс, одна SQLite. Конкурентная запись почти отсутствует, WAL этого хватает.
