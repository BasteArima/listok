# Нормализация ввода (`internal/entry`)

Пакет из чистых функций, без БД. Каждое правило покрывается табличным тестом (`entry_test.go`, `coverage_test.go`). При изменении правил дополни таблицу тестов.

## API пакета

| Функция | Что делает |
|---|---|
| `Parse(raw, Options) Result` | один токен → `Entry{Value, Kind}`, `Host` (если сокращён), `Warnings`, `Err` |
| `ParseMany(text, Options) []Result` | пачка: разделители — перевод строки, пробел, таб, `,`, `;`. Строки с `#` в начале пропускаются, повторы → `ErrDuplicate` |
| `NewIndex()` → `Add/Remove(listID, Entry)` | индекс записей всех списков в памяти (потокобезопасный) |
| `Index.CoveredBy(Entry) []Ref` | какие записи покрывают данную, включая точное совпадение |
| `Index.Covers(Entry) []Ref` | какие записи строго уже данной (станут лишними) |
| `Compact([]Entry) []Entry` | убрать повторы и покрытое, отсортировать: домены → IPv4 → IPv6. Для сборки фида |

Ошибки: `ErrEmpty`, `ErrInvalid`, `ErrPublicSuffix`, `ErrTooBroad`, `ErrDuplicate`. Предупреждения: `WarnPrivate`, `WarnFakeIP`.

## Разбор токена

Сначала по краям снимаются пробелы и кавычки `"'<>`. Порядок проверок:

1. **CIDR** (`netip.ParsePrefix`) → адрес сети (`10.1.2.3/8` → `10.0.0.0/8`), тип `cidr4`/`cidr6`.
2. **IP** (`netip.ParseAddr`) → `/32` или `/128`. Адрес с зоной (`fe80::1%eth0`) отклоняется.
3. IPv4-mapped IPv6 (`::ffff:1.2.3.4`, `::ffff:1.2.3.0/120`) превращается в IPv4.
4. **URL**: если в токене есть `/ : ? # @`, он разбирается как URL (без схемы подставляется `http://`), берётся хост. Хост-IP идёт по пп. 1–2, иначе как домен.
5. **Домен**: нижний регистр, без точки в конце, `*.` и `.` в начале снимаются. IDN → punycode (нестрогий профиль idna: `_` в метках разрешён). Метки: `[a-z0-9_-]`, 1–63 символа, не начинаются и не кончаются на `-`. Всего до 253 символов. TLD из одних цифр (`1.2.3`) отклоняется.

## Хост или регистрируемый домен

forkop ставит домены как `domain_suffix`: `youtube.com` покрывает и все поддомены. Поэтому из `www.youtube.com` или `rr3---sn-xxx.googlevideo.com` по умолчанию берётся **регистрируемый домен по ICANN** — метка перед ICANN-суффиксом (`icannSuffix`), а исходный хост кладётся в `Result.Host`, чтобы интерфейс показал «что именно добавится». `Options.ExactHost` («только этот хост») оставляет хост целиком.

**Частная часть Public Suffix List не учитывается** (D-026): `raw.githubusercontent.com` → `githubusercontent.com`, `user.github.io` → `github.io`, а `notion.site`, `akamaized.net`, `supabase.co`, `ondigitalocean.app`, `com.ru` добавляются как обычные домены. Для браузера это границы cookie, для маршрутизации — платформы, которые нужно пускать в туннель целиком.

## Отклоняется

- ICANN-суффикс целиком (`com`, `co.uk`, `gov.uk`, `app`) и одиночные метки (`localhost`).
- Пустое, длиннее 253 символов, с недопустимыми символами.
- Префиксы короче `/8` (IPv4) или `/16` (IPv6), включая `0.0.0.0/0` и `::/0`: это почти наверняка ошибка.

## Предупреждения (не блокируют)

- `WarnFakeIP`: пересечение с FakeIP sing-box (`198.18.0.0/15`, `fc00::/18`). Скорее всего, IP скопирован с клиента, у которого домен уже идёт через туннель.
- `WarnPrivate`: частные и служебные диапазоны (`10/8`, `172.16/12`, `192.168/16`, `127/8`, `100.64/10`, `169.254/16`, мультикаст, `fc00::/7`, `fe80::/10` и т. п.).
- Покрытие (считается через `Index` уровнем выше, не в `Parse`): запись уже покрыта (`CoveredBy`) или новая запись делает лишними более узкие (`Covers`).

## Проверка покрытия

Домен покрыт, если в индексе есть он сам или любой его суффикс по границе метки (`notyoutube.com` **не** покрыт `youtube.com`). Подсеть покрыта префиксом того же семейства с маской не длиннее, содержащим её адрес. `Covers` для доменов и подсетей перебирает индекс целиком: при десятках тысяч записей это дёшево.

`Compact` сортирует подсети по (семейство, адрес, длина маски) и сравнивает каждую только с последней оставленной. Корректность сверяется с наивным O(n²) на случайных данных (`TestCompactMatchesNaive`).
